# Antigravity Workflow

This project will be implemented incrementally with Antigravity in VS Code.

For each phase:

1. Ask Antigravity to inspect the current state first.
2. Give only the current phase requirements.
3. Do not ask it to rewrite unrelated areas.
4. Run the application's validation commands.
5. Review the result visually.
6. Bring the Antigravity report back to the project owner for the next prompt.

Never jump directly to the final ceremony animation before the interaction/state foundation is stable.
